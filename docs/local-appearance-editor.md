# 本机可视化编辑入口

在项目文件夹内双击 **编辑网页外观.command**。终端窗口会启动编辑器，并自动用浏览器打开 `http://127.0.0.1:8766/_editor/`。请保留终端窗口；关掉窗口或按 Control+C 即停止服务。若 macOS 阻止首次打开，可以右键该文件选择“打开”；也可以让 Codex 启动编辑器。

左侧调整强调色、底色、新闻标题颜色、电脑与手机字号、粗细、上下留白、页面最大宽度和电脑来源列数。右侧实时展示同一份新闻网页；顶部“电脑／手机”切换预览宽度。

- 拖动只是预览，不改文件。“撤销未保存修改”回到上次保存的设置。
- “预览默认样式”也只是预览，点击“保存到本地项目”才覆盖保存。
- 保存写入 `config/appearance.json` 与 `public/appearance.css`，不会自动提交或发布。
- 满意后告诉 Codex **“发布本地外观调整”**，即可按现有流程发布到所有设备。
- 预览使用本地新闻快照；没有最近 72 小时的数据时可能显示空榜单。编辑器不自动抓取新闻，也不调用 Gemini；翻译请在正式网站使用。

公开网页仅加载最终样式，不包含编辑按钮或面板。编辑面板和保存接口只在本机运行，监听 127.0.0.1；保存操作校验本机来源与会话令牌，不接收文件路径或任意 CSS。不将其部署为公网后台。

命令行备用启动：

```sh
python3 -m scripts.frontend_editor
```

默认端口已占用时先关闭旧编辑器，或者使用 `--port 8767`。无需额外安装软件依赖、开通服务或填写 API 密钥。
